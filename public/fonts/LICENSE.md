# Fonts in this folder

Both files are variable TrueType fonts downloaded from the google/fonts
repository (https://github.com/google/fonts, `ofl/` directory) and are
licensed under the SIL Open Font License 1.1. They are used at runtime by
opentype.js to build glyph outlines for the 3D glass word.
